[ THE DEAL ]

C = cooperate / stay silent; D = defect / betray.
+-------+--------+--------+
| A / B | B: C   | B: D   |

| A: C  | (3, 3) | (0, 5) |
| A: D  | (5, 0) | (1, 1) |

+--------------------------------------------------------------------------+
|                           [ STRATEGY DEBRIEF ]                           |
+--------------------------------------------------------------------------+
Strategy interpretation:
One round: D earns 5 rather than 3 against C, and 1 rather than 0 against D.
So D strictly dominates C; (D,D) is the unique one-shot Nash equilibrium.
Both cooperating earns (3,3), better for both than mutual defection (1,1).
Always cooperate can be exploited; always defect gives up mutual cooperation.
Random ignores history; Tit-for-tat starts C and copies the last opposing move.
Tit-for-tat responds to both defection and a later return to cooperation.
Repeated play permits responses, but cooperation and convergence are not guaranteed.
